# 📊 Dashboard Project

Аналитический дашборд для мониторинга складских операций и работы сотрудников.

Проект разработан на **Python + Streamlit** и предназначен для получения данных из PostgreSQL, отображения аналитических отчетов, поиска по результатам и мониторинга текущих складских процессов.

---

## 🚀 Возможности

### 📊 Аналитические отчеты

Дашборд позволяет выбирать и одновременно отображать несколько аналитических отчетов.

В проекте доступны отчеты:

* Не выданные заявки
* Неотобранные артикулы с разбивкой на подтипы
* Статистика по отобранным и неотобранным артикулам
* Статусы заявок отгрузки
* Количество отборов сотрудников по волнам
* Отборы сотрудников по волнам
* Средняя скорость отбора в час
* Выданные клиентам заказы
* Операции по ресурсам

Список отчетов хранится централизованно в файле `queries.py`.

---

## 🔎 Поиск по таблицам

Для отчетов с большим количеством данных предусмотрен встроенный поиск.

Поиск выполняется **сразу по всем столбцам таблицы**.

Доступны следующие функции:

* 🔎 поиск по таблице;
* ⌨️ запуск поиска клавишей `Enter`;
* 🔎 запуск поиска кнопкой **«Найти»**;
* ✖️ очистка поискового запроса;
* отображение только найденных строк;
* поиск без изменения исходных данных отчета.

Поиск выполняется по текстовому представлению значений всех столбцов, поэтому можно искать как по текстовым полям, так и по числовым значениям, датам и другим данным.

---

## 📥 Выгрузка в Excel

Результаты отчетов можно скачать непосредственно из интерфейса дашборда.

Для каждого отчета доступна кнопка:

**⇩ Скачать**

Данные выгружаются в формате:

```text
.xlsx
```

Для создания Excel-файла используется библиотека **OpenPyXL**.

### Экспорт учитывает поиск

Если перед скачиванием был выполнен поиск, в Excel попадут **только найденные строки**.

Например:

1. открыть отчет;
2. ввести значение в поле поиска;
3. нажать **«Найти»**;
4. проверить найденные строки;
5. нажать **«⇩ Скачать»**.

В результате будет сформирован Excel-файл только с отфильтрованными данными.

Если поиск не выполнялся, в Excel выгружается полный результат отчета.

## 📈 Визуализация

Для некоторых отчетов предусмотрено автоматическое построение графиков.

Используется библиотека **Plotly**.

Доступны:

* столбчатые диаграммы;
* линейные графики для временных данных.

Графики можно включать и отключать через настройки боковой панели.

---

## 📋 Отображение нескольких отчетов

Дашборд поддерживает одновременный просмотр нескольких отчетов.

В боковой панели можно выбрать:

* один отчет;
* несколько отчетов.

Также доступен выбор расположения:

* **в одну колонку**;
* **в две колонки**.

Это позволяет одновременно сравнивать результаты нескольких отчетов.

---

## ⚙️ Настройки отображения

В боковой панели доступны настройки:

* расположение отчетов в одну или две колонки;
* показ/скрытие графиков;
* показ/скрытие сводной статистики;
* показ/скрытие таблиц с данными.

---

## 🔄 Обновление данных

Данные загружаются из **PostgreSQL**.

Для ускорения работы используется кеширование Streamlit.

В боковой панели доступна кнопка:

**🔄 Обновить данные**

При её нажатии:

1. кеш данных очищается;
2. приложение перезапускает отображение;
3. данные повторно загружаются из PostgreSQL.

---

## 🔥 Часто используемые отчеты

На главной странице отображаются наиболее часто запускаемые отчеты.

Для каждого отчета показывается:

* название;
* количество запусков;
* кнопка быстрого запуска.

Статистика формируется на основании действий пользователей и хранится в локальной SQLite-базе.

Это позволяет быстро запускать наиболее востребованные отчеты без необходимости искать их в списке.

---

## 📝 Логирование

В проекте реализовано логирование действий пользователей.

Для хранения логов используется **SQLite**.

Логируются:

* посещения дашборда;
* просмотры отчетов;
* параметры запросов;
* время действия;
* User-Agent;
* session ID;
* IP-адрес, если он доступен приложению.

### Идентификация посетителей

Для подсчета уникальных посетителей используется `session_id`.

Это позволяет корректнее считать пользователей, чем использование только IP-адреса, поскольку несколько пользователей могут работать через один IP-адрес.

Файл базы логов:

```text
logs/dashboard_logs.db
```

### Основные файлы

#### `app.py`

Главный файл приложения.

Отвечает за:

* интерфейс;
* выбор отчетов;
* параметры запросов;
* отображение таблиц;
* поиск;
* фильтрацию;
* построение графиков;
* сводную статистику;
* экспорт данных в Excel;
* взаимодействие с пользователем;
* отображение часто используемых отчетов.

#### `queries.py`

Содержит SQL-запросы проекта.

Запросы организованы в словаре и вызываются из `app.py` по названию отчета.

Это позволяет отделить SQL-логику от интерфейса приложения.

#### `config.py`

Содержит настройки подключения к PostgreSQL.

Параметры подключения берутся из `.env`.

#### `logger.py`

Отвечает за:

* создание SQLite-базы логов;
* запись действий пользователей;
* хранение пользовательских сессий;
* получение статистики использования отчетов.

#### `pages/`

Содержит дополнительные страницы Streamlit-приложения.

#### `.streamlit/config.toml`

Содержит настройки Streamlit и оформления интерфейса.

# 🔐 Настройка подключения к PostgreSQL

Параметры подключения рекомендуется хранить в `.env`.

Пример:

```env
DB_HOST=localhost
DB_PORT=5432
DB_NAME=postgres
DB_USER=postgres
DB_PASSWORD=your_password
```

> Файл `.env` не должен публиковаться в GitHub.

Добавьте его в `.gitignore`:

```text
.env
```

# 🗄 Настройка базы данных

Проект использует **PostgreSQL** в качестве основной базы данных.

Перед запуском необходимо:

1. установить PostgreSQL;
2. создать базу данных;
3. предоставить пользователю необходимые права;
4. указать параметры подключения в `.env`.

Структура таблиц и необходимые SQL-запросы зависят от используемой WMS-системы.

# ▶️ Запуск

После настройки окружения выполните:

```bash
streamlit run app.py
```


# 🧹 Кеширование

Для ускорения работы используется механизм кеширования Streamlit:

```python
@st.cache_data
```

Подключение к PostgreSQL кешируется отдельно:

```python
@st.cache_resource
```

При необходимости кеш данных можно очистить кнопкой:

**🔄 Обновить данные**

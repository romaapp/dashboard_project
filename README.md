# 📊 Dashboard Project

Аналитический дашборд для мониторинга складских операций и работы сотрудников.

Проект разработан на **Python + Streamlit** и предназначен для получения данных из PostgreSQL, отображения аналитических отчетов, поиска по результатам и мониторинга текущих складских процессов.

---

## 🚀 Возможности

### 📊 Аналитические отчеты

Дашборд позволяет выбирать и просматривать различные отчеты, в том числе:

* Не выданные заявки
* Неотобранные артикулы с разбивкой на подтипы
* Статистика по отобранным и неотобранным артикулам
* Статусы заявок отгрузки
* Количество отборов сотрудников по волнам
* Отборы сотрудников по волнам
* Средняя скорость отбора в час
* Выданные клиентам заказы
* Операции по ресурсам

Список отчетов хранится централизованно в файле с SQL-запросами.

---

## 🔎 Поиск по таблицам

Для отчетов с большим количеством строк предусмотрен поиск.

Поиск выполняется сразу по всем столбцам таблицы.

Также доступны:

* очистка поискового запроса;
* фильтрация результатов;
* скачивание результатов в CSV.

---

## 📥 Экспорт данных

Результаты отчетов можно выгружать в CSV.

Экспорт учитывает текущую фильтрацию таблицы, поэтому можно сначала выполнить поиск, а затем скачать только необходимые строки.

---

## 📈 Визуализация

Для некоторых отчетов предусмотрено автоматическое построение графиков.

Используется библиотека **Plotly**.

Доступны:

* столбчатые диаграммы;
* линейные графики для временных данных.

Графики можно включать и отключать через настройки боковой панели.

---

## ⚙️ Настройки отображения

В боковой панели доступны настройки:

* отображение одного или двух отчетов в строке;
* показ/скрытие графиков;
* показ/скрытие сводной статистики;
* показ/скрытие таблиц с данными.

---

## 🔄 Обновление данных

Данные загружаются из PostgreSQL.

Для ускорения работы используется кеширование Streamlit.

Доступна кнопка:

**🔄 Обновить данные**

При её нажатии кеш очищается и данные загружаются заново.

---

## 🔥 Часто используемые отчеты

На главной странице отображаются наиболее часто запускаемые отчеты.

Статистика формируется на основании действий пользователей и хранится в локальной SQLite-базе.

Для каждого отчета отображается количество запусков.

---

## 📝 Логирование

В проекте реализовано логирование действий пользователей.

Для хранения логов используется **SQLite**.

Логируются:

* посещения дашборда;
* просмотры отчетов;
* параметры запросов;
* время действия;
* User-Agent;
* session ID;
* IP-адрес, если он доступен приложению.

### Идентификация посетителей

Для подсчета уникальных посетителей используется `session_id`.

Это позволяет корректнее считать пользователей, чем использование IP-адреса, поскольку несколько пользователей могут работать через один IP-адрес.

Файл базы логов:

```text
logs/dashboard_logs.db
```

### Основные файлы

#### `app.py`

Главный файл приложения.

Отвечает за:

* интерфейс;
* выбор отчетов;
* параметры запросов;
* отображение таблиц;
* поиск;
* фильтрацию;
* графики;
* экспорт;
* взаимодействие с пользователем.

#### `queries.py`

Содержит SQL-запросы проекта.

Запросы организованы в словари и вызываются из `app.py` по названию отчета.

#### `config.py`

Содержит настройки подключения к PostgreSQL.

Параметры подключения берутся из `.env`.

#### `logger.py`

Отвечает за:

* создание SQLite-базы логов;
* запись действий пользователей;
* хранение пользовательских сессий;
* получение статистики.

#### `.streamlit/config.toml`

Содержит настройки Streamlit и оформления интерфейса.

# 🔐 Настройка подключения к PostgreSQL

Параметры подключения рекомендуется хранить в `.env`.

Пример:

```env
DB_HOST=localhost
DB_PORT=5432
DB_NAME=postgres
DB_USER=postgres
DB_PASSWORD=your_password
```

> Файл `.env` не должен публиковаться в GitHub.

Добавьте его в `.gitignore`:

```text
.env
```

# 🗄 Настройка базы данных

Проект использует PostgreSQL в качестве основной базы данных.

Перед запуском необходимо:

1. установить PostgreSQL;
2. создать базу данных;
3. предоставить пользователю необходимые права;
4. указать параметры подключения в `.env`.

Структура таблиц и необходимые SQL-запросы зависят от используемой WMS-системы.

---

# ▶️ Запуск

После настройки окружения выполните:

```bash
streamlit run app.py
```

После запуска Streamlit предоставит адрес приложения, например:

```text
http://localhost:8501
```

Откройте его в браузере.

---

# 📊 Работа с отчетами

После запуска:

1. Выберите необходимые отчеты в боковой панели.
2. При необходимости задайте параметры.
3. Выберите настройки отображения.
4. Просмотрите результаты.
5. Используйте поиск для фильтрации данных.
6. При необходимости экспортируйте результаты.
